# Privacy

Student Garden for Android works offline. It has no Internet permission, analytics, advertising, account service, or cloud sync. Notes, tasks, study records, settings and media stay in private app storage.

Microphone permission is requested only to record a card. System file pickers grant access only to selected files. Notification permission supports focus completion, lesson reviews, task deadlines, agenda starts, due flashcards and scheduled habits. Exact-alarm access is optional; without it Android can batch alerts. Notifications use generic text without your note, task, card or habit content. Private receivers restore schedules after reboot, application updates and clock/time-zone changes. Category switches, a daily practice time and a test notification are available in Settings. Reminder delivery history stays in private local preferences. Force-stopping the app pauses alarms until it is opened again.

The optional app lock uses Android device credentials. This is an access gate, not separate database encryption. Android system backup is disabled. Exported backup ZIP files are readable and should be stored privately. Import validates paths and sizes and merges new records without replacing existing records.

Uninstalling removes private app data. Export a backup first. Trash supports recovery of deleted records within the app. The Android app does not automatically transfer data from the separate web application.
